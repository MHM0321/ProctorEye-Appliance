# Security policy

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability.

Email **boxloid0321321@gmail.com** with:

- the affected version;
- clear reproduction steps;
- the expected and observed behavior;
- the practical impact;
- a minimal proof of concept with sensitive data removed.

Do not include passwords, API keys, license files, payment data, or real candidate evidence. You should receive an acknowledgement within seven days. This is a student-maintained project, so no formal response-time guarantee or bug-bounty program is offered.

## Supported versions

Security fixes are normally shipped only in the latest release. Upgrade to the newest release before reporting an issue that may already be fixed.
